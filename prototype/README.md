# 云枢智学 - 页面原型

## 数据模型架构

```
┌──────────────────────────────────────────────────────────────┐
│                       学科 (Subject) × 8                      │
│  AI应用与智能体开发 │ AI大模型开发 │ AI具身智能机器人开发       │
│  AI嵌入式_机器人开发 │ AI测试 │ AI运维 │ AI视觉设计             │
│  AI视频与短剧创作                                            │
│  每个学科有独立的图标、描述、主题色；共 8 个学科、18 个阶段      │
│                                                              │
│  每个学科下可挂载多个 阶段 (Catalog)：                         │
│  AI应用与智能体开发 → [大模型基础, Prompt 工程, 智能体开发实战] │
│  AI大模型开发 → [Transformer 原理, 模型微调]                   │
│  AI具身智能机器人开发 → [机器人运动学, 感知与决策]              │
│  AI嵌入式_机器人开发 → [嵌入式系统基础, 边缘AI部署]             │
│  AI测试 → [AI测试基础, 模型评测]                               │
│  AI运维 → [AI基础设施, MLOps]                                  │
│  AI视觉设计 → [AI视觉创意, 商业设计实战]                       │
│  AI视频与短剧创作 → [AI视频生成, 短剧创作实战, 商业化与交付]     │
└───────┬──────────────────┬───────────────────────────────────┘
        │ 一对多            │ 一对多
        ▼                   ▼
┌───────────────┐  ┌──────────────────────┐
│ 题库 (Question)│  │   学习路线 (Route) × 4 │
│ 共 44 道题，    │  │   引用 courseIds 数组  │
│ 挂载在阶段下    │  │   课程1 → 课程2 → ...  │
└───────────────┘  └──────────┬───────────┘
                              │ 多对多
                   ┌──────────┴───────────┐
                   │  B站课程库 (Course) × 14 │
                   │  BV号唯一标识，14 门课程  │
                   │  可被多条路线引用         │
                   └──────────────────────┘
```

## 项目结构

```
prototype/
├── index.html          # 原型入口页（学员端 / 管理端两个入口）
├── css/                # 公共样式，学员前台与管理后台共用
│   ├── common.css      # 公共样式（变量、基础重置、按钮、表单、通用组件）
│   ├── layout.css      # 学员前台布局与业务样式（导航栏、页脚、卡片、练习/面试等）
│   └── admin.css       # 管理后台样式
├── js/
│   ├── common.js       # 公共脚本（图标库、模拟数据、工具函数、弹窗、数据仓库）
│   ├── portal.js       # 学员前台公共逻辑（导航态、页脚、登录守卫）
│   ├── admin.js        # 管理后台框架（侧边栏、顶栏、登录守卫）
│   └── pages/          # 各页面业务脚本
├── assets/
│   └── images/covers/  # 课程封面（本地 SVG）
├── portal/             # 学员前台（C端）
│   ├── index.html      # 首页
│   ├── login.html      # 登录页
│   ├── register.html   # 注册页
│   ├── forgot-password.html # 找回密码页
│   ├── profile.html    # 个人中心页
│   ├── questions.html  # 题库列表页
│   ├── practice.html   # 刷题练习页
│   ├── wrong-book.html # 错题本页
│   ├── routes.html     # 学习路线页
│   ├── ai-config.html  # AI面试配置页
│   ├── ai-interview.html    # AI模拟面试页
│   ├── interview-report.html  # 面试报告页
│   └── interview-history.html # 面试历史页
└── admin/              # 管理后台
    ├── login.html      # 后台登录页
    ├── index.html      # 数据看板
    ├── subjects.html   # 学科管理（含阶段）
    ├── courses.html    # B站课程库
    ├── questions.html  # 题库管理
    ├── question-bank.html  # 面试题库管理
    ├── routes.html     # 学习路线管理
    ├── students.html   # 学员管理
    ├── users.html      # 用户管理
    ├── roles.html      # 角色管理
    ├── logs.html       # 操作日志
    └── settings.html   # 系统设置
```

> 根目录 `index.html` 为原型入口页；两个端的页面均以 `../css/`、`../js/` 引用顶层公共资源；跨端跳转用 `../admin/xxx.html`、`../portal/xxx.html`。

## 页面清单

### 学员前台页面（13个）

| 页面 | 文件名 | 功能说明 |
|------|--------|----------|
| 首页 | portal/index.html | 平台介绍、功能入口、统计数据 |

| 注册 | portal/register.html | 手机号注册、密码强度检测 |

| 刷题 | portal/practice.html | 倒计时、答题卡、上一题/下一题 |

## 已实现功能

### 前台页面（13个）
- ✅ 响应式布局，支持移动端
- ✅ 导航栏用户下拉菜单（后台账号登录后显示管理后台入口）
- ✅ 登录页 Tab 切换（账号密码 / 手机验证码）；注册页密码强度检测
- ✅ 找回密码三步式流程
- ✅ 个人中心信息管理

#### 首页增强
- ✅ **快速开始**：规划学习路线、随机练习 10 题、继续上次学习、开始 AI 面试
- ✅ **学习统计**：连续学习天数、答题正确率、总练习数
- ✅ **近 7 天练习**：柱状图展示每日练习量，今日高亮
- ✅ **新手引导**：首次使用三步引导蒙层（localStorage 记录）
- ✅ **计数动画**：统计数据数字递增动画效果

#### 题库 & 刷题
- ✅ 题库阶段筛选、难度筛选、类型筛选
- ✅ 题目"查看解析"和"开始练习"两种入口
- ✅ **两种练习模式**：顺序练习、随机练习（Fisher-Yates 洗牌）
- ✅ **简答题AI批改**：textarea输入、AI评分动画、评分展示、关键点提示、参考答案
- ✅ **继续上次练习**：localStorage 持久化，断点续练（关闭页面后仍可继续）
- ✅ **键盘快捷键**：← → 切换题目，Enter提交，? 查看快捷键面板

#### 错题本
- ✅ 错题筛选（阶段、时间、状态、排序）
- ✅ 标记已掌握、移除错题
- ✅ **错题重做模式**：逐题练习、提交批改、连续正确3次自动标记掌握
- ✅ **批量操作**：复选框选择、批量标记掌握/移除
- ✅ **高频错题Top3**：按错误次数排序展示

#### AI面试
- ✅ AI面试配置页（方向、难度、题目数量；超时固定 5 分钟）
- ✅ AI面试对话式交互、实时评分
- ✅ **中断恢复**：localStorage 持久化，检测未完成面试提供继续/重选
- ✅ **进度面板**：已回答数量、平均分、进度条、计时器
- ✅ **面试摘要侧边栏**：题目列表+评分、面试统计
- ✅ **语音输入**：浏览器语音识别，不支持时降级为模拟识别并提示
- ✅ 网络状态检测（在线/离线指示器）

#### 面试报告 & 学习路线
- ✅ **待提升项**：每条 = 问题描述 + 一句指导性建议文案（不给具体阶段，也不做跨页跳转）
- ✅ **改进建议**：编号建议列表
- ✅ **能力提升建议**：推荐题目 / 推荐课程 / 推荐再次面试 3 张卡，纯文案说明，不带跳转按钮
- ✅ **分数趋势对比**：与上次同方向面试对比（↑提升/↓下降）
- ✅ **学习路线**：8 个学科卡片单选切换，路线头部统计 + 有序课程列表，支持「去B站学习」

#### 面试题库管理
- ✅ **题目列表**：跨知识库总览，列为「题目 / 来源 / 难度 / 主题 / 操作」，题干关键字 + 知识库 + 主题 + 难度筛选，分页（10/20/50 条每页）
- ✅ **来源列**：知识库名 + 文档标题 + 第 N 题；手工录入标「手工录入 / 无源文档」，手动导入 Markdown 标「手动导入」
- ✅ **三种来路**：知识库文档解析（主）、手工录入、手动导入 Markdown，列表与详情都标来源
- ✅ **只看未分类**：单独勾选框，与主题下拉互斥，用于复查还没标主题的题
- ✅ **主题下拉**：带题数统计，0 题的词表主题也列出，词表外主题标「· 词表外」
- ✅ **题目详情**：主题/难度/标签、题干、参考答案、来源（知识库 / 文档名 第 N 题）
- ✅ **录入题目**：选知识库 + 填题干/参考答案/主题/难度/标签，新题标记为「手工录入」，无来源文档
- ✅ **上传 Markdown 导入**：传 .md 题库文档（按 #~### 标题切题），两段式 —— 先选知识库并解析预览（前 3 道样例 + 行号），再统一指定主题/难度/标签批量入库；文件不入库，来源只留文档名
- ✅ **编辑主题与难度**：只能改这两项，题干与参考答案不给后门，提示按来路区分（上传解析的改源文件重传 / 手工录入的删掉重录）
- ✅ **删除题目**：逻辑删除确认，提示按来路区分（上传的 Markdown 系统不留存，删了只能重新上传）
- ✅ **两种空态**：只看未分类时提示「都标好主题了」，其余情况提示「没有符合条件的题目」

## 使用方式

1. 直接在浏览器中打开 `portal/index.html` 即可预览学员前台
2. 访问 `admin/login.html` 进入管理后台登录页（直接看数据看板可开 `admin/index.html`）
3. 所有页面均使用本地CSS和JS，无需服务器；公共资源在顶层 `css/`、`js/`，请保持目录结构完整

## 测试说明

- 学员端首次访问自动登录演示学员「林小满」；退出后可使用任意非空账号密码登录
- 管理端演示账号 **admin / admin123**（任意非空账号密码均可登录）
- 演示学员信息与模拟数据在 `js/common.js` 的 `CloudData` 中定义；学员端导航中的「管理后台」入口仅在后台账号登录后显示
- 在管理端「系统设置 → 原型工具」中可以一键重置全部演示数据

## 技术说明

- 纯HTML + CSS + JavaScript实现，无外部依赖
- 使用CSS变量统一管理主题色
- 模拟数据存储在 `js/common.js` 的 `CloudData` 对象中，后台可编辑数据由 `App.getDB()` 持久化
- 课程封面使用 `assets/images/covers/` 下的本地 SVG
- 交互效果通过原生JS实现
